**Title:** I made a fork of KDE's Icons-Only Task Manager with real spacers

I wanted to group pinned apps without creating empty .desktop launchers, so I
made a fork of KDE's Icons-Only Task Manager.

- Right-click an app and choose “Add spacer to the right”.
- Adjust all spacer widths in the widget's Appearance settings.
- Remove a spacer from the same app's context menu.
- Spacer positions persist and follow their apps when icons move.

Source and instructions:
https://github.com/TheGreatOilPainter/icons-only-spacers

It is a native Plasma plugin. It has been tested on openSUSE Slowroll with
Plasma 6.7.5 and Qt 6.11.2; other versions are not yet verified. It requires
compilation or a package built for your library versions, and is not a
one-click KDE Store installation.

This is an independent fork of KDE's task manager with the upstream authorship
and licenses preserved. Reports from other setups are welcome, especially with
distribution, Plasma/Qt versions, and reproducible steps.
